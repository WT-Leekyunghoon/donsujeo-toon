## 캐릭터 (참고 이미지: `docs/characters/`)
- **하마 (주인공, 모든 툰에 등장)**: 회색빛 파란 하마. ETF를 하나씩 배워가는 초보 투자자. 실수도 하고 깜짝 놀라기도 하지만 결국 깨닫고 정리하는 역할.
- **수달**: 갈색 몸에 흰 배. 차분하게 개념을 설명해 주는 친구.
- **비버**: 갈색, 앞니 두 개. 계산기·숫자·꼼꼼한 확인 담당.
- **흰곰**: 아이보리색. 맞장구치고 정리를 함께하는 친구.
- 이름은 아직 없음 — 사용자가 이름을 정하면 여기 추가.

## 툰 형식 (12시 슬롯, 하루 1편)
- 한 장짜리 이미지, 가로 16:9, 맨 위 굵은 제목 `하마의 ETF 도전기 - ○○편`, 아래 4컷.
- 게시는 **4장 캐러셀**(컷마다 1장, 세로 4:5, 위에 제목 띠) — 휴대폰에서 보기 좋게 (2026-10-07 사용자 요청). `tools/split_panels.py` 로 자동 분할. 그래서 4컷은 **같은 크기 칸 4개를 흰 여백으로 띄워서** 그리게 한다.
- 흐름: ① 하마의 궁금증/착각 → ② 친구의 설명 → ③ 깨달음/놀람 → ④ 정리·다짐.
- 대사는 **칸 위쪽 말풍선 안에만**. 칸 아래 캡션에 대사 반복 금지, "(하트)" 같은 괄호 설명 글자 금지, 숫자·종목명·로고 금지.
- 말풍선 1개 = 최대 2문장, 25자 안팎.
- 매 편 친구 1~3마리를 섞고, 칸 배경색·소품·표정을 바꿔 같은 그림 반복을 피한다.

## 말투
- 반말, 친근한 친구 톤. 짧은 문장. 이모지는 본문에 2~3개(🦛 시그니처).
- 용어는 초보 눈높이 한 줄 비유("총보수 = 매년 빠지는 보관료").

## 게시글 본문 형식
- **해시태그·출처 표기 금지** (2026-10-06 사용자 요청) — 툰·상식 글 모두 해시태그와 "(출처: …)" 줄을 달지 않는다. 수치 확인은 기사 원문으로 하되 본문엔 쓰지 않는다. 러너도 게시 직전에 지운다.
- **툰(12시)**: 주제 한 줄 + 핵심 2~4줄 + 체크포인트(✔) 1~2개. 회차 번호는 본문에 쓰지 않는다(history 로 추적).
- **09:50·17시 = ETF 상식 글 (경제 동향 접목)** — 2026-10-06 사용자 요청. 경제 뉴스 요약이 아니라 **ETF 지식**이 주인공이고, 그날 경제 동향은 도입부 한두 줄의 연결고리로만 쓴다.
  - 09:50 (아침 글, 2026-10-07~ 10시에서 변경): 밤사이 해외 증시·금리·환율 등 아침 이슈 → 관련 ETF 개념 하나(예: 금리↑ → 채권 ETF·듀레이션).
  - 17시: 오늘 국내 증시·경제 이슈 → 관련 ETF 개념 하나(예: 환율↑ → 환헤지(H) ETF).
  - 구성: 질문형 제목 📌 → 오늘 이슈 1~2줄(수치는 기사 원문 확인) → ETF 개념 설명 3~5줄 → ✔ 체크포인트 1~2개. 출처·해시태그 없음.
  - 같은 날 아침 글·17시·12시 툰의 ETF 개념이 겹치지 않게, 직전 7일 글과도 겹치지 않게.
  - 토·일·공휴일: 그 주 이슈를 엮은 ETF 상식(09:50), 다음 주 일정과 관련된 ETF 체크포인트(17시).
- 본문은 **475자 이하** (Threads 500자 제한).

## 주제 풀 (툰) — 직전 10편과 겹치지 않게
- **ETF**: ETF 개념 / 이름 읽는 법 / 구성종목 / 총보수·실부담비용 / 거래량·호가 / 괴리율 / 분배금 / 레버리지·인버스 / 환헤지(H) / 상장폐지 / 지수(코스피200 등) / 채권·파킹형 / 연금계좌 ETF / ISA
- **주식 기초**: 배당·배당락 / 시가총액 / PER·PBR / 호가창 / 공시 / 우선주
- **경제 상식**: 기준금리 / 물가 / 환율 / 국채 / CPI·고용지표
- **습관·심리**: 적립식 / 추격매수 / 분할매수 / 리밸런싱 / 비상금
- **다루지 않는 것**: 부동산, 코인 시세, 해외 개별 종목.

## 절대 금지
- 특정 ETF·종목 매수·매도 권유, 목표가, 수익 보장. 상품명은 설명 예시로만.
- 확인 안 된 수치 단정. 뉴스 수치는 기사 원문에서 확인한 것만.
- 정치, 특정 인물·회사 비난, 공포 조장.
