## 캐릭터 (참고 이미지: `docs/characters/`)
**역할 고정 (2026-10-07 사용자 확정 — 첫 인사 글 기준, 모든 툰·글에서 이 역할을 지킨다)**
- **하마 (주인공, 모든 툰에 등장)**: 회색빛 파란 하마. ETF를 하나씩 배워가는 초보 투자자. 궁금해하고, 착각하고, 깜짝 놀라지만 결국 깨닫고 다짐하는 역할. 설명은 하지 않는다.
- **수달 = 차분한 설명 담당**: 갈색 몸에 흰 배. 개념을 쉬운 비유로 차분하게 풀어 준다. "~란 건 말이야" 처럼 조곤조곤. 개념 정의·원리 설명 대사는 수달 몫.
- **비버 = 숫자 꼼꼼 확인 담당**: 갈색, 앞니 두 개, 계산기 소품. 비용·수익률·비율·날짜 같은 숫자와 조건을 꼼꼼히 따져 확인한다. "잠깐, 이거 확인해 봤어?" 같은 체크 대사는 비버 몫. (툰 이미지엔 숫자 금지 규칙은 그대로 — 대사로 '확인하자'만.)
- **흰곰 = 옆에서 같이 정리 담당**: 아이보리색. 하마 옆에서 맞장구치고, 마지막에 핵심을 한 줄로 같이 정리해 준다. 정리·다짐 컷(④)은 하마+흰곰이 기본.
- 툰 컷 배치 기본형: ① 하마 궁금증/착각 → ② 수달 설명 → ③ 비버 숫자·조건 확인(하마 놀람) → ④ 하마+흰곰 정리·다짐. 주제에 따라 친구 1~3마리만 써도 되지만 **역할은 바꾸지 않는다**(수달이 숫자 체크, 비버가 개념 설명 같은 혼용 금지).
- 글(10시·17시)에서 캐릭터를 언급할 때도 같은 역할로: "수달이 그러는데 ~", "비버가 꼭 확인하래 ✔", "흰곰이랑 정리해 보면 ~".
- 이름은 따로 정하지 않고 종 이름으로 부른다 (하마·수달·비버·흰곰, 2026-10-16 사용자 확인).

## 툰 형식 (12시 슬롯, 하루 1편)
- 한 장짜리 이미지, **세로 4:5, 2×2 배치(위 2칸·아래 2칸, 읽는 순서 ①왼위 ②오른위 ③왼아래 ④오른아래)** (2026-10-16 사용자 선택 — 휴대폰에서 확대 없이 보이게), 맨 위 굵은 제목 `하마의 ETF 도전기 - ○○편`.
- 게시는 **4장 캐러셀**(컷마다 1장, 세로 4:5, 위에 제목 띠) — 휴대폰에서 보기 좋게 (2026-10-07 사용자 요청). `tools/split_panels.py` 로 자동 분할. 그래서 4컷은 **같은 크기 칸 4개를 흰 여백으로 띄워서** 그리게 한다. (분할기는 가로 1줄·2×2 모두 인식)
- **흐름 (v4)**: ① 상황 — 하마가 일상에서 ETF 문제에 부딪힘(착각·실수) → ② 수달 설명(비유 장면으로 그림) → ③ 비버 숫자·조건 체크, 하마 리액션 크게 → ④ **펀치라인** — 반전·자기 개그·흰곰의 한마디로 웃기게 끝내고 교훈은 본문 글이 맡는다. 4컷이 "다짐" 한 줄로 끝나는 공식은 피한다.
- 대사는 **칸 안 위쪽 말풍선 안에만**(칸 테두리 밖·아래로 나가면 안 됨). 한 칸 말풍선 최대 2개, 각 25자 안팎. 칸 아래 캡션 금지, "(하트)" 같은 괄호 설명 글자 금지, 숫자·종목명·로고 금지.
- 매 편 장소·소품·표정을 바꿔 같은 그림 반복을 피한다.

### 캐릭터 개성 (v4) — 이름은 따로 없음: 하마는 하마, 수달은 수달, 비버는 비버, 흰곰은 흰곰으로 부른다 (2026-10-16 사용자 확인)
- **하마**: 의욕 앞서는 덜렁이. 먹을 것(수박·도넛)에 약하고 뭐든 음식에 비유해 착각함. 놀라면 귀가 쫑긋+땀방울. 편이 쌓일수록 조금씩 똑똑해져서, 가끔은 하마가 먼저 맞히고 친구들이 놀라는 회차도 넣는다.
- **수달**: 차분한 선생님 타입, 작은 칠판·안경·조개 소품. 비유 장인. 말버릇 "~란 건 말이야".
- **비버**: 꼼꼼한 계산왕, 계산기·돋보기·체크리스트를 늘 듦. 말버릇 "잠깐, 확인해 봤어?". 너무 꼼꼼해서 웃음 포인트가 되기도 함.
- **흰곰**: 느긋한 맞장구 담당, 핫초코·담요. ④컷에서 한마디로 상황을 정리하거나 엉뚱한 한마디로 받아침.
- 역할(설명=수달, 숫자=비버, 정리=흰곰, 배우는 주인공=하마)은 그대로.

## 게시글 본문 형식
- **해시태그·출처 표기 금지** (2026-10-06 사용자 요청) — 툰·상식 글 모두 해시태그와 "(출처: …)" 줄을 달지 않는다. 수치 확인은 기사 원문으로 하되 본문엔 쓰지 않는다. 러너도 게시 직전에 지운다.
- **툰(12시)**: 주제 한 줄 + 핵심 2~4줄 + 체크포인트(✔) 1~2개. 회차 번호는 본문에 쓰지 않는다(history 로 추적).
- **10시·17시 = ETF 상식 글 (경제 동향 접목)** — 2026-10-06 사용자 요청. 경제 뉴스 요약이 아니라 **ETF 지식**이 주인공이고, 그날 경제 동향은 도입부 한두 줄의 연결고리로만 쓴다.
  - 10시 (아침 글, 2026-10-13~ 다시 10시): 밤사이 해외 증시·금리·환율 등 아침 이슈 → 관련 ETF 개념 하나(예: 금리↑ → 채권 ETF·듀레이션).
  - 17시: 오늘 국내 증시·경제 이슈 → 관련 ETF 개념 하나(예: 환율↑ → 환헤지(H) ETF).
  - 구성: 질문형 제목 📌 → 오늘 이슈 1~2줄(수치는 기사 원문 확인) → ETF 개념 설명 3~5줄 → ✔ 체크포인트 1~2개. 출처·해시태그 없음.
  - 같은 날 아침 글·17시·12시 툰의 ETF 개념이 겹치지 않게, 직전 7일 글과도 겹치지 않게.
  - 토·일·공휴일: 그 주 이슈를 엮은 ETF 상식(10시), 다음 주 일정과 관련된 ETF 체크포인트(17시).
- 본문은 **450자 이하** (Threads 500자 제한 — 러너가 끝에 스하리·반하리 문구를 붙이므로 여유를 둔다).
- **모든 글·툰 끝에 스하리·반하리 문구** (2026-10-19 사용자 요청): 예) "항상 스하리 반하리 해줄 거지? 🙏". 러너(`add_closing`)가 게시 직전에 자동으로 붙이니 본문에 따로 쓰지 않아도 된다. 직접 쓰면 러너는 중복해서 붙이지 않는다.

## 주제 풀 (툰) — 직전 10편과 겹치지 않게
- **ETF**: ETF 개념 / 이름 읽는 법 / 구성종목 / 총보수·실부담비용 / 거래량·호가 / 괴리율 / 분배금 / 레버리지·인버스 / 환헤지(H) / 상장폐지 / 지수(코스피200 등) / 채권·파킹형 / 연금계좌 ETF / ISA
- **주식 기초**: 배당·배당락 / 시가총액 / PER·PBR / 호가창 / 공시 / 우선주
- **경제 상식**: 기준금리 / 물가 / 환율 / 국채 / CPI·고용지표
- **습관·심리**: 적립식 / 추격매수 / 분할매수 / 리밸런싱 / 비상금
- **다루지 않는 것**: 부동산, 코인 시세, 해외 개별 종목.

## 절대 금지
- 특정 ETF·종목 매수·매도 권유, 목표가, 수익 보장. 상품명은 설명 예시로만.

- 정치, 특정 인물·회사 비난, 공포 조장.
