# 하마의 ETF 도전기 — 콘텐츠 생성 런북 (예약 작업용, v3 2026-10-06)

**게시는 GitHub Actions 가 한다** — 이 작업은 콘텐츠를 만들어 `queue/daily/YYYY-MM-DD/` 에
커밋하는 것까지만. 직접 Threads 에 게시하지 말 것. 사람은 없다고 가정하고, 막히면 사유만 보고하고 종료.

예약 작업은 하루 2번 돈다.

| 실행 | 만드는 것 |
|---|---|
| **오전 (KST 09:30)** | `0950.json` ETF 상식 글(09:50 게시) + `1200.json`·`1200.png` 하마툰 |
| **오후 (KST 16:2x)** | `1700.json` ETF 상식 글 |

## 0. 준비
- 저장소: `git clone https://github.com/WT-Leekyunghoon/donsujeo-toon.git` (push 가 필요하면 먼저
  `add_repo`(owner `WT-Leekyunghoon`, repo `donsujeo-toon`, access `push`) 로 세션에 붙이고 클론).
- 읽을 것: `docs/persona.md`(필수), `state/history.json`(직전 10편 툰 topic — 중복 금지), `docs/actions-setup.md`(파일 형식).
- 오늘(KST) 날짜 폴더에 이미 해당 파일(또는 `.done`)이 있으면 그 파일은 건너뛴다.

## 0-1. 주말·공휴일 미리 준비 (오전 실행에서만, 2026-10-07 사용자 요청)
쉬는 날엔 PC 가 꺼져 있어 오전 실행(툰)이 못 돈다. 그래서 **쉬는 날 바로 전 평일의 오전 실행**이 그 연휴 분량을 미리 만든다.
1. 오늘 몫(`0950.json` → push, 그다음 오늘 툰)을 먼저 끝낸다.
2. 쉬는 날 확인: Google 캘린더 `ko.south_korea#holiday@group.v.calendar.google.com` 을 내일부터 14일 조회해
   description 이 "공휴일"인 날(기념일 제외)을 확인 → `python tools/offdays.py <오늘> [state/holidays_kr.json 에 없는 공휴일 ...]`.
   새로 생긴 공휴일(임시공휴일·선거일 등)은 `state/holidays_kr.json` 에도 추가. 캘린더 조회가 안 되면 `offdays.py` 만으로 판단.
3. 출력이 비어 있으면(내일 평일) 끝. 출력된 날마다 `queue/daily/<그날>/` 에:
   - `0950.json` — 토·일·공휴일 규칙(그 주 이슈를 엮은 ETF 상식). "오늘·밤사이" 같은 당일 표현 금지, 그날 읽어도 어색하지 않게.
   - `1200.json` + `1200.png` + 분할본(`split_panels.py`) — 하마툰 (2장 절차 그대로, 날마다 다른 주제).
   - `1700.json` — 다음 주 일정과 관련된 ETF 체크포인트. 연휴 마지막 날이 아니면 다음 날 일정·기초 개념 위주로.
   - 각 날의 개념·툰 주제가 서로, 그리고 직전 7일과 겹치지 않게.
4. 날짜별로 만들 때마다 커밋·push (중간에 끊겨도 앞선 날은 남게). 툰을 못 만든 날은 json 도 만들지 말고 보고에 남긴다.
5. 보고에 "○/○~○/○ 연휴분 미리 준비: 날짜별 파일" 한 줄 추가.
(오후 실행은 클라우드라 쉬는 날에도 돈다 — `1700.json` 이 이미 있으면 건너뛴다.)

## 1. ETF 상식 글 (09:50·17시 공통 — 경제 동향 접목)
- 경제 뉴스 요약이 아니라 **ETF 지식 글**이다. 그날 경제 동향은 도입부 연결고리로만 쓴다 (persona 의 "09:50·17시 = ETF 상식 글" 규칙).
- 웹 검색으로 그날 이슈 기사 원문을 열어 **발행일·수치를 확인**한 것만 쓴다.
  - 09:50 (`0950.json`, 2026-10-07~ 옛 `1000.json`): 밤사이 뉴욕증시·미 국채금리·환율 등 → 관련 ETF 개념 1개.
  - 17시: 오늘 국내 증시·경제 이슈 → 관련 ETF 개념 1개.
  - 토·일·공휴일: 09:50 그 주 이슈 엮은 ETF 상식, 17시 다음 주 일정 관련 ETF 체크포인트.
- 개념은 그날 12시 툰·다른 슬롯·직전 7일 글(`state/history.json` posts·`queue/daily/` 의 .done)과 겹치지 않게.
- 형식: `{"type":"news","title":"...","body":"..."}` (러너에선 news 타입 그대로). **출처 표기·해시태그 금지** (사실 확인은 원문으로 하되 본문엔 출처를 쓰지 않는다).
- **오전 실행은 09:30 시작 → 09:50 게시라 시간이 빠듯하다. `0950.json` 을 먼저 만들어 3장대로 바로 커밋·push(09:45 전 목표)한 뒤 툰 작업을 한다.**
- **body 475자 이하** (`len(body)` 로 직접 확인). 예측·단정·종목 추천·정치 금지. 상품명은 예시로만.
- 연결할 만한 이슈가 없으면 이슈 없이 ETF 기초 개념 글로 쓴다.

## 2. 하마툰 (오전 실행만, Chrome + Gemini, PC 필요)
1. 주제: persona 주제 풀에서 직전 10편과 겹치지 않게 1개. 4컷 대사를 먼저 짠다. 대사는 persona 의 캐릭터 역할 고정(수달=설명, 비버=숫자 확인, 흰곰=같이 정리, 하마=배우는 주인공)을 따른다.
2. 크롬 도구(claude-in-chrome)로 새 탭에서 `https://gemini.google.com/app` (로그인돼 있음).
3. 참고 이미지 첨부: `docs/characters/01-cast-lineup.png`, `02-hippo-turnaround.png` 를
   `/mnt/user-data/outputs/` 로 복사 → 입력창 왼쪽 **+** 클릭(메뉴가 열리면 **Escape 누르지 말 것** —
   누르면 업로드 입력이 사라진다) → `find` 로 `input[type=file]`(accept=image/*) 찾기 → `file_upload`.
   메뉴의 "파일" 항목은 누르지 않는다(네이티브 창이 떠서 멈춤).
4. 프롬프트는 **줄바꿈 없이 한 줄로** 입력 (줄바꿈하면 그 자리에서 전송돼 잘린다). 포함할 것:
   - "이미지 만들기:" + 첫 첨부 그림체 그대로(얇은 짙은 갈색 단선, 플랫 파스텔, 음영·그라데이션·3D 금지), 하마 비율은 두 번째 첨부
   - 가로 16:9, **정확히 4컷을 한 줄로 가로 나란히**(같은 크기 칸 4개, 칸 사이 흰 여백 — 나중에 컷별로 잘라 올림), 맨 위 제목 "하마의 ETF 도전기 - ○○편"
   - 컷별 장면 + 말풍선 대사, "대사는 칸 위쪽 말풍선 안에만"
   - "칸 아래 캡션 박스 금지(대사 중복 금지), 같은 장면 반복 금지, 괄호 설명 글자 금지, 숫자·종목명·로고 금지, 한글 철자 정확"
5. 결과 검수 (스크린샷/확대): 4컷인지, 같은 컷 반복 없는지, 대사 오탈자, 그림체. 문제 있으면 같은 대화에서 1~2회 수정 요청.
6. 다운로드: 이미지 위에 마우스 → "원본 크기 이미지 다운로드" **한 번** 클릭 →
   `C:\Users\wealt\Downloads` 를 device_list_dir 로 확인해 새 `Gemini_Generated_Image_*.png` 생겼는지 검증
   (연속 클릭은 크롬이 조용히 무시함). Downloads 접근이 없으면 device_request_folder_access 로 요청.
7. device_stage_files 로 가져와 `queue/daily/<날짜>/1200.png` 로 저장.
7-1. **휴대폰용 4장 분할** (2026-10-07 사용자 요청): `python tools/split_panels.py queue/daily/<날짜>/1200.png`
   → `1200-1.png`~`1200-4.png`(4:5 세로, 각 장 위에 제목 띠) 생성 + `1200.json` 에 `"panels"` 기록. 4컷이 정확히 나뉘었는지 확인.
   (8번에서 json 을 만든 뒤 실행할 것. 안 나뉘면 러너가 게시 때 다시 시도하고, 그래도 안 되면 한 장으로 올린다.)
8. `1200.json`: `{"type":"toon","title":"하마의 ETF 도전기 - ○○편","topic":"○○","body":"..."}`
   — **해시태그 금지**, 회차 번호도 쓰지 않는다. 475자 이하.
9. Gemini 한도·오류로 이미지를 못 만들면 툰은 건너뛰고(json 도 만들지 않음) 보고에 명시. 크롬 탭은 닫는다.

## 3. 커밋
- 최신 `main` 으로 맞춘 뒤 만든 파일만 `git add` → commit → `git push origin main`, `git ls-remote` 로 반영 확인. 강제 push 금지.
- push 권한이 없으면: 파일을 `/mnt/user-data/outputs/` 에 두고 크롬으로
  `https://github.com/WT-Leekyunghoon/donsujeo-toon/upload/main/queue/daily/<날짜>` 에서 file_upload → Commit changes,
  이후 `git pull` 로 실제 반영 확인.
