# 돈수저툰 — 콘텐츠 생성 런북 (Cowork 예약 작업용, v2)

매일 아침 1회 실행. **게시는 GitHub Actions 가 한다** — 이 작업은 콘텐츠를
만들어 `queue/daily/` 에 커밋하는 것까지만 한다. 직접 Threads 에 게시하지 말 것.
사람은 없다고 가정하고, 막히면 사유만 보고하고 종료한다.

## 1. 생성할 날짜 정하기

- 오늘(KST)을 D0 로 둔다. 생성 대상 = D0 + "D0 다음에 이어지는 모든 비영업일".
  - 비영업일 = 토·일 + 공휴일. 공휴일은 구글 캘린더에서 확인:
    `mcp__Google_Calendar__list_calendars` 로 대한민국 휴일 캘린더를 찾아
    앞으로 7일간 `list_events`.
  - 예) 금요일 → 금·토·일 (월이 공휴일이면 월도). 수요일인데 목요일이 공휴일
    → 수·목. 평일이고 내일도 평일 → 오늘만.
- repo 를 클라우드 샌드박스에서 `git clone https://github.com/WT-Leekyunghoon/donsujeo-toon.git`
  로 받아, 이미 `queue/daily/<날짜>/` 에 5개 파일이 있는 날짜는 건너뛴다.
- 오늘이 토·일·공휴일이면 (전날 이미 생성됨) 파일 존재만 확인하고 종료.

## 2. 읽을 것

- `docs/persona.md` — 말투·4컷 구조·주제 풀·금지사항 (절대 위반 금지).
- `state/history.json` — 직전 10편 제목·주제 (중복 금지), 계정 정보.
- `docs/actions-setup.md` — 파일 형식.

## 3. 날짜별로 5개 파일 생성 → `queue/daily/YYYY-MM-DD/`

| 파일 | 내용 |
|---|---|
| `1000.json` | 그림툰 spec (sample_spec 형식 + topic/title/body, body 의 EP 는 `{N}`) |
| `1200.json` | 10시 툰 보충 설명·팁 — `{"type":"tip","title","body","attach_panel":3}` |
| `1400.json` | 경제 뉴스 해설 — `{"type":"news","title","body"}` |
| `1700.json` | 그림툰 spec (10시와 다른 주제) |
| `1900.json` | 17시 툰 보충 설명·팁 |

- **10시 툰 = 운용사 ETF 브랜드 시리즈** (2026-09-02부터, persona.md 의
  "운용사 ETF 브랜드 시리즈" 섹션의 순서·규칙을 따른다):
  - 다음 순번 판단: `state/history.json` episodes 의 topic 중 `운용사툰:` 으로
    시작하는 것 + `queue/daily/` 미게시(.done 아닌) 파일들을 보고, 아직 안 다룬
    첫 운용사를 고른다. topic 은 반드시 `운용사툰: 브랜드(운용사)` 형식.
  - 생성 전 네이버 검색으로 현행 브랜드명 확인. 시리즈 완주 후엔 주제 풀로 복귀.
- 17시 툰: persona 주제 풀에서 선택 — ETF·국내 주식 기초·경제 상식·습관/심리
  (부동산·코인 금지), 직전 10편 + 이번에 만드는 다른 날짜 것과 중복 금지.
  습관·심리·절세 쪽 우선. 10시 시리즈 편과 소재가 겹치지 않게.
  그림은 persona 의 "그림 다양화 규칙"을 매 편 적용 (bg 4색, prop 미중복, friend 활용,
  flip/tilt 변화).
- 팁(body): 해당 툰 주제의 심화 1가지 — 실전 체크법, 흔한 실수, 용어 한 줄 비유
  등 4~6문장 반말. 이모지 최대 2개. 마지막에 독자 질문 1줄. 시작에
  "오전에 올린 툰 봤어?" 같은 연결 멘트. `{PERMALINK}` 는 원본 툰 링크로 치환됨.
  특정 종목 추천·수익 보장·미확인 수치 금지 (persona 금지사항 동일 적용).
- 뉴스(body): `mcp__PlayMCP__NaverSearch-search_news` 로 당일 국내 경제·증시·금리
  뉴스를 검색해 1건 선택 → 초보 눈높이로 무슨 일인지, 왜 중요한지, ETF 투자자
  관점의 일반론적 시사점 순으로 5~8문장. 언론사명으로 출처 언급 ("오늘 ○○
  기사 보니까"). 예측·단정·종목 추천 금지. 정치 이슈는 피한다.
  **토·일·공휴일치 1400 은 당일 뉴스 대신 "이번 주 경제 소식 정리"** — 그 주에
  있었던 주요 소식 2~3개를 묶어 짧게 정리하는 주간 리캡 글로 쓴다 (토요일은
  한 주 정리, 일요일은 다음 주 일정·체크포인트 위주 변형도 좋다).
- 뉴스가 하나도 마땅치 않으면 1400.json 은 만들지 않는다 (그 슬롯은 자동 생략됨).

## 4. 커밋 (브라우저 GitHub 업로드)

- 크롬 도구 로드 후 `https://github.com/WT-Leekyunghoon/donsujeo-toon/upload/main/queue/daily/<날짜>`
  로 이동 → file_upload 로 그 날짜의 json 들 업로드 → Commit changes.
- PC/크롬이 꺼져 있으면: 만든 내용을 보고에 남기고 종료 (다음날 재시도).
  Actions 는 daily 파일이 없으면 툰 슬롯만 에버그린 큐로 폴백한다.
- 에버그린 큐(`queue/q*.json`)가 5편 미만이면 툰 spec 을 2~3편 만들어
  `queue/` 에도 업로드해 둔다.
